# 3b 사람이 보는 확인 (약 10분)

자동 시험이 볼 수 없는 것(보이는 모양, 읽히는지, 초점, Dock, 아이콘)을 사람이 화면 앞에서 본다. [3b 계획](../2026-11-25-phase3b-browser-ui.md) 작업 11 2단계.

도우미 스크립트 `manual-3b.sh`(이 폴더, 시험 기기에도 한 벌)가 임시 홈과 임시 브라우저 데이터로 Pegboard.app을 켜고, 확인 창과 알림을 하나씩 띄운다. 시험 훅은 켜지 않는다(사람이 누르는 진짜 길). 쓰는 사람은 보고 누르기만 한다. 앱 위치는 `PEGBOARD_MANUAL_APP=<Pegboard.app>`으로 준다(시험 기기의 한 벌은 마지막 개발 빌드를 가리킨다).

터미널 창 하나를 화면 한쪽에 두고 명령을 친다. 각 명령은 5초 세고 나서 확인 창을 띄운다(그 사이 사람 창을 누르거나 다른 앱으로 간다). 어긋나는 것이 있으면 번호와 함께 적어 둔다.

## 순서

1. **켜기**: `manual-3b.sh start`.
   - [ ] 사람 창 하나만 뜬다. 프로필 선택 화면이 뜨지 않는다.
   - [ ] Dock의 아이콘이 주황색 판에 구멍 격자와 페그 하나다(임시 아이콘이 아니다). Finder에서 앱을 목록 보기로 봐도(작은 크기) 형태가 보인다.
   - [ ] 앱 메뉴 이름이 "Pegboard"이고 "Pegboard 정보", "Pegboard 종료"가 있다.
2. **업로드 확인 창, 초점**: `manual-3b.sh upload`. 세는 동안 사람 창의 주소창을 누르고 글을 천천히 계속 친다.
   - [ ] 에이전트 창이 따로 열린다: 창 틀이 짙은 호박색이고, 창 메뉴(또는 Mission Control)의 제목이 "Pegboard 에이전트"다. 사람 창은 원래 색이다. (세션을 처음 만들 때 에이전트 창이 앞으로 나올 수는 있다. 확인 창이 뜰 때가 중요하다.)
   - [ ] 확인 창이 에이전트 창 위쪽 가운데에 뜬다. 뜨는 순간에도 사람 창에 치던 글이 끊기지 않는다(초점이 그대로).
   - [ ] 확인 창이 읽힌다: 제목 "에이전트가 확인을 요청합니다", 굵은 첫 줄 `세션 s_… · 프로필 PegboardAgent`, 흐린 줄 "에이전트가 붙인 세션 이름: «업로드»", 호스트 `127.0.0.1`, 대상 페이지, 파일의 경로 전체(`…/pbm/www/report.txt`)와 크기, "읽을 수 있는 쪽" 줄, "60초 안에 답하지 않으면 거부됩니다".
   - [ ] 버튼은 "허용"과 "거부" 둘이고 "거부"가 기본 버튼이다. 뜬 직후 잠깐(1초 남짓) 버튼이 흐리다.
   - [ ] "허용"을 누르면 터미널에 결과와 `종료 코드 0`이 나오고, 에이전트 창의 시험 페이지 파일 칸에 `report.txt`가 들어 있다.
3. **앱이 뒤에 있을 때(Dock)**: `manual-3b.sh state`. 세는 동안 Finder(또는 다른 앱)를 눌러 앞으로 가져온다.
   - [ ] 확인 창이 뜨면 Dock의 Pegboard 아이콘이 한 번 튄다. Finder가 그대로 앞에 있다.
   - [ ] 쿠키 창: 호스트 `127.0.0.1`, 이름 `demo`, 값 `hello`, 경로가 보인다.
   - [ ] Pegboard로 돌아가 Esc를 누르면(거부) 터미널에 `policy_denied … (reason: denied)`가 나온다.
4. **이 세션에서 계속 허용**: `manual-3b.sh upload-dir`.
   - [ ] 버튼이 셋이다("이 세션에서 계속 허용" 포함). 그것을 누르면 업로드된다.
   - [ ] `manual-3b.sh upload-dir`를 한 번 더: 확인 창 없이 바로 끝난다.
5. **저장소, 시간 초과(선택, 1분)**: `manual-3b.sh storage`를 띄우고 아무것도 누르지 않는다.
   - [ ] 60초 뒤 창이 닫히고 터미널에 `(reason: timed_out)`이 나온다.
6. **프로필 메뉴**: 사람 창의 오른쪽 위 프로필 단추를 누른다.
   - [ ] 사람의 프로필만 있고 `PegboardAgent`(에이전트 프로필)는 "다른 프로필"에 없다. (에이전트 창의 프로필 메뉴에는 그 에이전트 프로필 자신이 보인다. 알려진 것.)
7. **설정 화면** (사람 창의 주소창에 친다):
   - [ ] `chrome://settings/people`: 구글 로그인이나 동기화를 켜라는 단추가 없다.
   - [ ] `chrome://password-manager/settings`: "비밀번호 저장 여부 확인"(비밀번호 저장 제안)이 꺼져 있다. 자동 로그인도 꺼져 있다.
   - [ ] `chrome://settings/help`: "Pegboard 정보", 본문의 제품 이름이 Pegboard다. (로고 그림은 Chromium 것 그대로다. 알려진 것.)
   - [ ] 어느 화면에도 "조직에서 관리" 표시가 없다.
8. **데몬 포기 알림**: 사람 창을 눌러 둔 채 `manual-3b.sh giveup`(데몬을 1분 안에 네 번 죽인다).
   - [ ] 사람 창 위에 "Pegboard 에이전트 데몬이 멈췄습니다" 알림이 뜨고, 초점이 사람 창에 그대로다. 문구가 읽힌다. 버튼은 "다시 시작"과 "닫기".
   - [ ] "다시 시작"을 누르고 몇 초 뒤 `manual-3b.sh status`에 데몬 pid가 나온다.
9. **끄기**: `manual-3b.sh stop`. 임시 파일이 지워지고 남은 프로세스가 없다고 나온다.
